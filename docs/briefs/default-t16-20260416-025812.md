# Benchmark Brief — T-16: Live Scoreboard with Polling

## Requirements
- Add a `/api/scores` JSON endpoint in `app.py` that returns the top N scores as JSON. Write a small JavaScript module (vanilla JS, no framework) that polls this endpoint on an interval, diffs the result, and updates the table DOM. Render the initial table server-side for fast load; JS takes over after mount. Add the "last updated" counter as a separate JS-driven element. Touch `app.py`, the scoreboard template, and a new static JS file.

## Constraints
- No schema changes.
- Follow existing project conventions and styles.
- Prefer minimal scope matching the task only.

## Scope
- full-stack

## Visual QA Target
- Scoreboard page that auto-refreshes the top scores every 10 seconds without a full page reload; a small "Last updated: Xs ago" counter ticks up between refreshes.

## Acceptance Criteria
- The described user-visible or API behavior is implemented.
- The change stays within the stated task scope.
- Tests are added or updated when the task requires code verification.
