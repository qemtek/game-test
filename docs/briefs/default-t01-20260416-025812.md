# Benchmark Brief — T-01: Active Nav Highlight

## Requirements
- Add active-state styling to the shared navigation template so the link matching the current route is highlighted. Touch only the base layout template and the CSS. Use Flask's `request.endpoint` (or `request.path`) passed to the template to apply an `active` class.

## Constraints
- No schema changes.
- Follow existing project conventions and styles.
- Prefer minimal scope matching the task only.

## Scope
- frontend-only

## Visual QA Target
- Screenshot of the nav bar with the current page link visually distinguished (e.g. brighter green, underline, or background pill) from inactive links.

## Acceptance Criteria
- The described user-visible or API behavior is implemented.
- The change stays within the stated task scope.
- Tests are added or updated when the task requires code verification.
