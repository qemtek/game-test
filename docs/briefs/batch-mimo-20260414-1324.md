# Batch: Player Profile

## Ticket: Add player profile page with stats

### Requirements
- GET /api/player/<name> — JSON: {name, rank, total_games, avg_score, top_scores:[{rank,score,date}]}
- GET /player/<name> — HTML page: player heading, top-5 scores table, overall rank, total games, average score
- Dark theme matching existing pages

### Implementation Notes
- All code in app.py only, tests in main test file only
- Query scores table (columns: id, name, score, created_at or similar — check schema)
- Rank = position among all players by best score (1 = highest)
- No new dependencies

### Acceptance Criteria
1. /api/player/<name> returns correct JSON
2. /player/<name> renders HTML with all stats
3. Rank is correct relative to other players
4. 404 if player not found
