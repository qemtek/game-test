# Benchmark Brief — T-08: Sortable Scoreboard Columns

## Requirements
- Add `?sort=` and `?order=` query parameters to the scoreboard route and apply Python-side sorting before passing rows to the template. In the template, render column header links that toggle order between `asc` and `desc`. Show a `▲` or `▼` character next to the active sort column using a Jinja2 conditional. No JS required.

## Constraints
- No schema changes.
- Follow existing project conventions and styles.
- Prefer minimal scope matching the task only.

## Scope
- backend+frontend

## Visual QA Target
- Scoreboard table with clickable column headers; clicking "Score" re-sorts descending, clicking "Date" re-sorts by date, with a small arrow indicator on the active sort column.

## Acceptance Criteria
- The described user-visible or API behavior is implemented.
- The change stays within the stated task scope.
- Tests are added or updated when the task requires code verification.
